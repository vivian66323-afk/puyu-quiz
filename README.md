# 菩語生活測驗｜你的居家 Lifestyle DNA

菩語國際設計的居家風格測驗，單頁靜態網站，掛在 GitHub Pages。

## 結構

```
index.html          全部的版面、題庫與邏輯（約 35 KB）
assets/img/         59 張選項圖，依「題目 id-選項 key」命名，逐題 lazy load
```

## 測驗流程

1. **情境選擇** — 預售屋客變／新成屋／老屋翻新／局部改造
2. **八張圖片題** — 畫、椅、花器、燈、杯、色票、窗景、門把
3. **四題狀態題** — 針對「現在住的地方」自評，1–4 分

## 計分

- 每個選項帶兩個價值標籤，第一個記 2 分、第二個記 1 分，再乘題目權重 `w`
- 16 個原型各自綁兩個價值，取加權總分最高者；同分時比第一價值
- 狀態題總分 4–16，分四段燈號：綠 ≤7、黃 ≤10、橙 ≤13、紅 ≤16
- 結果 = 原型 × 燈號 × 情境，三者組合出文案

## 結果卡

結果頁可用 canvas 輸出 1080×1210~1290 的 PNG。手機支援 `navigator.share` 時直接跳系統分享，否則下載檔案。
